# ShowIn

Stake NIM. ShowIn. Get it back.

Nimiq Pay Mini App for Cycle II — attendance bonds.

## Run

```bash
cd showin
npm install
npm run dev
```

Open on your phone inside **Nimiq Pay** (LAN URL) or in a desktop browser for **demo mode**.

Demo mode stores events in `localStorage` if the Mini App SDK is not injected.

## Stack

Vite + React + TypeScript + `@nimiq/mini-app-sdk`

## MVP

Create event → join / stake → check-in → settle → receipt
